# Speech Error Elicitation Task

This repository contains code for a **naturalistic speech error elicitation task** designed to investigate speech error patterns as two participants work collaboratively to navigate several mazes. *Last updated March 18, 2026.*

**Who to contact:** hsierliu@mit.edu, sshuf@mit.edu

## Task Procedure

Each participant completes a ~2-minute training to learn the corresponding icon for each word. This phase includes: reading each word aloud while viewing the icon, completing a brief multiple-choice task, and typing the name of the icon. Participants then complete two sets of maze tasks, serving a different role in each. In Task 1, participant 1 will be the direction $${\color{green}giver}$$, and participant 2 will be the $${\color{orange}drawer}$$; vice versa for Task 2. Participants are trained in each role and asked to complete the following parts for each set.

### 1. Practice (3 rounds; ≈ 2–5 minutes each)
Participants are paired and assigned complementary roles:
- $${\color{green}Giver}$$: Sees the start and exit points of the maze  
- $${\color{orange}Drawer}$$: Sees which paths are valid or invalid  

In each round, partners are presented with *different* 4×4 mazes that share the same correct solution path (e.g., “between the cup and the tap”). Some paths may appear in one maze but not the other, preventing the participants from giving instructions based on directions (e.g., "go left") and ensuring participants use the icon names. The objective is to collaboratively identify the shortest valid path given each participant’s limited information:
- The $${\color{green}giver}$$ gives instructions on which route to take  
- The $${\color{orange}drawer}$$ reports whether the proposed path is valid or invalid, but does not suggest routes (since they cannot see the endpoint) 

Practice rounds are **untimed**.

### 2. Test (2 rounds; 6 minutes each)
The same role assignments from the practice phase are maintained. Participants now complete a larger **6×6 maze** with a 6-minute time limit.  
All other procedures remain identical to the practice phase.
